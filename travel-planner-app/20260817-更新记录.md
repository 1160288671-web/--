# 更新记录 · 2026-08-17

> 本轮聚焦「方案 HTML 地图渲染」的健壮性修复，解决地图丢失、无图页面难看、标记点过小、多地点全景展示等问题。

## 一、问题背景

用户在查看生成的方案 HTML 时发现三个问题：

1. **部分页面没有图**：某些天数因缺少地图点位，页面只有文字，显得很空。
2. **一天多个地点时地图太小**：需要能展示全景，让用户看清整体行程。
3. **地图标记点过小**：标记看不清，怀疑是高德 API 本身的限制。

排查后发现更深层的根因（见第三节）：并非地名定位失败，而是**高德 API 并发（QPS）限制**导致部分地图请求被限流，且错误被误当成图片保存。

## 二、改动清单

### 1. `server/lib/amap.ts`

- **请求限流**：新增 `throttle` 串行化队列，所有高德请求逐个发出，且保持 400ms 最小间隔，避免并发触发 `CUQPS_HAS_EXCEEDED_THE_LIMIT`（10021）。
- **错误体识别**：静态图返回若以 `{`（JSON）开头，判定为错误、返回 `null`，不再把错误 JSON 当 PNG 图片保存。
- **自动重试**：限流 / 网络错误自动重试 2 次，带递增退避。
- **地理编码缓存**：`geocodeCache` 按「城市 + 地名」缓存坐标，封面与每日地图复用，减少重复请求。
- **地理编码状态校验**：检查 `status === '1'` 才算成功。
- **标记点加大**：标记样式由 `mid` 改为 `large`（高德静态图最大档）。
- **新增地名文本标签**：`labels` 叠加显示景点名（白底黑字加粗），多点全景时更易辨认。
- **新增 `fetchCityMap`**：生成单个目的地城市概览图，作为无点位时的兜底。

### 2. `server/lib/render-plan.ts`

- **多地点全景图**：一天 ≥2 个地点时，地图尺寸从 `750*500` 调整为宽幅 `1024*560`，页面布局切换为「文字在上、整行宽幅地图在下」。
- **无图兜底**：
  - 当天无点位时，自动回退到目的地城市概览图（保证每页都有图）。
  - 连城市定位都失败时，显示复古风格的占位卡（粗黑描边 + 几何装饰），替代原有难看虚线框。
- 封面地图在无点位时同样回退到城市概览图。

## 三、根因分析

**核心根因**：高德 Web 服务 API 对个人 key 有 QPS 上限（约 3 次/秒），旧代码把「封面 + 每天」的地图请求一次性并发发出，超过上限后，后续请求被限流。

**放大问题**：高德限流时返回的是 **HTTP 200 + JSON 错误体**（如 `{"status":"0","info":"CUQPS_HAS_EXCEEDED_THE_LIMIT","infocode":"10021"}`），旧代码未校验内容类型，直接把这段 JSON 当成 PNG 图片存进 HTML，导致页面出现「破损 / 丢失」的地图。

## 四、验证结果

用厦门方案存档重新渲染，5 张地图（封面 + 4 天）全部返回有效 PNG，第二天地图恢复正常：

```
地图数量: 5
地图 0: PNG OK
地图 1: PNG OK
地图 2: PNG OK   ← 第二天（厦门大学 + 环岛路）
地图 3: PNG OK
地图 4: PNG OK
```

## 五、备注

- 修改均在服务端（Vite 插件内嵌 API），需重新点击「生成方案」才会用新模板渲染；若运行中的 dev server 未自动重启，需手动重启。
- 现有存档可通过再次渲染覆盖修复。

## 六、下一期计划（界面美化）

> 已与用户讨论确认，优先做以下四个方向（按优先级排序）。

### 1. 统一复古波普风（最高优先级）

把对话界面从当前暖色卡片风，整体改造成与生成的 HTML 方案一致的 1970s 杂志风：

- 奶油米色底 + 粗黑描边 + 三文鱼粉/天蓝/芥末黄/薄荷绿四色点缀。
- 引入与 HTML 方案一致的几何装饰（四分之一圆、同心圆环、星芒）。
- 标题、按钮改用粗黑描边 + 偏移阴影，强化杂志感。
- 目标：对话界面与最终方案视觉统一，形成产品记忆点。

### 2. 对话体验升级

- 气泡优化：区分用户/助手头像，气泡形态与配色套用复古风。
- 消息进入动画、助手「打字中」动效（配合已有 ProfileCarousel）。
- 快捷选项从圆形按钮改为卡片式选择，支持组合选择、更清晰的选中态。

### 3. 画像面板可视化

- ProfilePanel 从纯文字改为卡片式 + 图标。
- 增加「信息收集进度」可视化（进度条/完成度），一眼看出还缺哪些关键信息。
- 硬约束项（⚠ 标记）高亮显示。

### 4. 移动端适配优化

- 优化三栏布局在小屏的响应式表现（对话/画像/方案入口的合理堆叠）。
- 输入区、快捷选项、按钮的触摸优化。
- 全屏方案查看器（PlanViewer）在手机端的体验打磨。
